# Rishen & Lizaan — Wedding Website

**24 October 2026 · Highberry Vineyards & Venue · Somerset West, Cape Winelands, South Africa**

A luxury single-page wedding website built with pure HTML, CSS, and JavaScript.

## Preview

Open index.html in any modern browser to preview locally.

## Go Live (GitHub Pages — Free)

1. In this repo, go to **Settings → Pages**
2. Set Source to **Branch: main**, folder **/ (root)**
3. Click Save — your site will be live at https://rgangen24.github.io/Rishen---Lizaan-Wedding

## Replacing Placeholders

Search index.html for [ to find every editable field.

## Connect the RSVP Form

Replace the console.info block in the script with a fetch to Formspree or Netlify Forms.
